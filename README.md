# Gulf_Saas_Review

Middle East Software & SaaS Intelligence Platform — Independent reviews, Saudi Arabia ZATCA Phase 2 E-Invoicing certification, UAE Corporate Tax (9%), WPS payroll compliance, and localized bilingual comparisons.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Theme**: Forest (`#064734`), Leaf (`#E0FFC2`), and Cream (`#FFF8EF`)

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Key Features
- **SaaS Directory Index**: Single-line audit table for 50+ GCC business tools.
- **ZATCA & UAE Tax Checkers**: Verified status for Phase 2 cryptographic e-invoicing and corporate tax readiness.
- **Head-to-Head Comparisons**: Side-by-side matrices comparing implementation cost, Arabic RTL, and compliance.
- **Software Categories**: Dedicated directories for ERP, Accounting, CRM, HR & Payroll, Support, and E-commerce.
- **Software Search**: Live masthead software lookup with quick category filters.
